# Приборная панель Edtech KPI (закрытая)

Данные зашифрованы AES-256-GCM паролем, расшифровка в браузере.

## ⚠ ИСТОЧНИК ИСТИНЫ — `index.html`

GitHub Pages отдаёт `index.html`. **Только он** попадает в браузер.

Файл `edtech_panel_secure.html` в этом репозитории больше **не** обновляется
и удалён. Он породил ошибку: работа уходила в него, а сайт открывал
`index.html` — и 14 коммитов подряд были не видны на панели.

## Сборка и деплой

```bash
# одна команда: собрать → проверить → скопировать в index.html → коммит → push
bash ~/.hermes/scripts/deploy_edtech.sh

# только собрать и проверить, без push
bash ~/.hermes/scripts/deploy_edtech.sh --no-push
```

Скрипт **не пушит**, если не прошли проверки: баланс тегов, `node --check`
по всему JS, успешная расшифровка payload и наличие финмодели внутри.
Перед коммитом делается снимок в `~/.hermes/snapshots/ROLLBACK-deploy-*`.

Откат:

```bash
git checkout <commit> -- index.html && git push
```

## Пароль

Лежит в `~/.private_keys/edtech_panel_auth` (chmod 600, вне репозитория).
В коде страницы пароля нет — данные приходят из зашифрованного payload.
